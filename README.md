# GFX Game Booster Android

## English

Game Booster is an Android application designed to optimize your gaming experience by managing system resources, improving performance, and enhancing battery life.

### Key Features
* **Thermal Monitor:** Optional real-time monitoring of device temperature and RAM usage.
* **Performance Boosting:**
    * Disable thermal throttling.
    * Disable hardware overlays for direct GPU rendering access.
    * Auto-clear game cache.
    * OOM Killer immunity for high-priority gaming processes.
    * Enable high-performance modes, maximum CPU/GPU frequencies.
* **Game Ad Blocker:** System-wide ad blocking for games using Shizuku Private DNS.
* **Image Optimizer:** Inspects and compresses large game images (HD/FHD/4K) to SD to save storage.
* **App Control:** Force stop (Kill) or Freeze background applications to free up memory and CPU.
* **Resolution Tuner:** Change resolution and DPI per game, with native resolution reset capabilities.
* **Game Management:** Add games automatically or manually, export/import game configurations (JSON).
* **Game Foreground Service:** Monitor performance and quickly kill games and restore resolution.
* **Shizuku Integration:** Enables advanced, system-level control without permanent root.

### Prerequisites
This application requires root mode or [Shizuku](https://github.com/RikkaApps/Shizuku-API) application to be installed and authorized on your device.

## Português (Brasil)

O Game Booster é um aplicativo Android projetado para otimizar sua experiência de jogo, gerenciando recursos do sistema, melhorando o desempenho e prolongando a vida útil da bateria.

### Principais Funcionalidades
* **Monitor Térmico:** Monitoramento opcional em tempo real da temperatura do dispositivo e uso de RAM.
* **Aceleração de Desempenho:**
    * Desativa a limitação térmica.
    * Desativa overlays de hardware para acesso direto à GPU.
    * Limpeza automática de cache.
    * Imunidade ao OOM Killer para processos de jogos.
    * Ativa modos de alto desempenho, frequências máximas de CPU/GPU.
* **Bloqueador de Anúncios:** Bloqueio de anúncios em nível de sistema usando DNS via Shizuku.
* **Otimizador de Imagens:** Inspeciona e compacta imagens grandes de jogos (HD/FHD/4K) para SD, economizando armazenamento.
* **Controle de Apps:** Finaliza (Kill) ou Congela aplicativos em segundo plano para liberar memória e CPU.
* **Tuner de Resolução:** Mude a resolução e DPI por jogo, com capacidade de redefinir a resolução nativa.
* **Gerenciamento de Jogos:** Adicione jogos automaticamente ou manualmente, exporte/importe configurações de jogos (JSON).
* **Serviço de Primeiro Plano:** Monitore desempenho e feche jogos rapidamente, restaurando a resolução original.
* **Integração com Shizuku:** Habilita controle avançado de nível de sistema sem necessidade de root permanente.

### Pré-requisitos
Este aplicativo requer o modo root ativado ou o aplicativo [Shizuku](https://github.com/RikkaApps/Shizuku-API) instalado e autorizado no seu dispositivo.
